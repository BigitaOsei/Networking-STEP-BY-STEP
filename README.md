# TechStart Ltd - Small Company Network Project

## Project Overview
This project demonstrates a basic enterprise network design using VLANs and inter-VLAN routing (Router-on-a-Stick) for a small company called **TechStart Ltd**.

### Departments
- Sales
- Engineering
- Management
- Servers

### Devices Used
- 1 × Cisco Router (Border-RTR)
- 1 × Cisco Switch (Core-SW)

### Features Implemented
- VLAN segmentation
- Inter-VLAN routing
- Basic device security (enable secret, console & VTY passwords)
- Switch management interface
- PortFast on access ports
- Trunk link between Router and Switch
